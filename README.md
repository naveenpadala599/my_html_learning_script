# HTML Learning Journey

Personal practice repository for learning HTML fundamentals and common patterns.

This collection contains many small focused experiments I wrote while learning HTML. Each file explores a specific attribute, element, or concept so I can build a strong practical foundation.

## Topics Covered

- Basic structure and boilerplate
- Links (`href`, targets, relative paths)
- Images and the `alt` attribute
- Forms, inputs, buttons, checkboxes, and related attributes
- `id`, `name`, `value`, `type`, and `data-*` attributes
- Semantic roles (`role="button"`, `role="navigation"`, `role="alert"`, etc.)
- iframes and media elements
- Accessibility-related practices
- Small exploration scripts and experiments

## Purpose

This is a learning journal focused on understanding how HTML works in real pages. The goal is to write clean, accessible markup that I can use confidently in web projects.

---

**Note:** Files are named descriptively so I can easily find past practice examples.
